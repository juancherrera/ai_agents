## What is included

254 source notebooks, including the existing Lab 3 pack; five official CrewAI projects; and 344 community contribution entries. Community module maps cover eligible code/configuration documents; saved outputs, private environment files, profile data, databases, generated outputs, vendored packages, and checkpoint copies are excluded.

**Defaults:** no private configuration loading, no hosted calls, no servers or UI windows, no delivery, no course-data changes. Where actual integration is useful, learn the shape with fictional fixtures first. Original source files remain unchanged.

**Taxonomy:** `course/<week>/<lab-or-project>/`, `guides/<guide>/`, `setup/<lesson>/`, `community/<week>/<contribution>/notebooks/<lesson>/`, and community `project/` maps. Source names and locations are retained in each guide.

Coverage is recorded in [source-coverage.json](source-coverage.json). Verification results are in [verification.md](verification.md).
